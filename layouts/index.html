02 / METHOD

Direction is the job.
Execution is delegated.

A prompt is the start, not the proof. I ask agents to research, implement, test and revise. Useful work ends with an artifact, a real check and a clear account of what remains uncertain.

Different models take different roles: the current Node A Hermes conversation uses an OpenAI Codex subscription; Node B is the local GPU lane for inference and creative workloads when available. The machine and model used are choices, not a claim that every task runs locally.
